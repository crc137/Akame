# Akame
  
<img src="https://raw.coonlink.com/cloud/Akame/quiet.png" align="right" width="160" style="max-width: 100%" />

> Детектор изменений в логах входа и конфигурации аутентификации для Kali/Debian с индикатором в панели Xfce и опциональными уведомлениями в Telegram.

Два состояния: спокойное, когда последняя проверка прошла успешно, и угроза, если что-либо изменилось или сам проверяющий перестал работать. Третьего состояния нет — всё, что не подтверждено как чистая проверка, намеренно отображается как угроза.
